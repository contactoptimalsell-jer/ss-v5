# 🔍 Trouver la section Root Directory

## 📍 Où se trouve Root Directory ?

Dans la page Settings, vous devriez voir un menu de gauche avec plusieurs sections. Cherchez :

1. **Dans le menu de gauche** (sous la barre de recherche) :
   - General
   - **Build and Development Settings** ← C'est ici !
   - Domains
   - Environments
   - etc.

2. **Cliquez sur "Build and Development Settings"** dans le menu de gauche

3. **Dans cette page**, vous devriez voir :
   - Framework Settings (ce que vous voyez actuellement)
   - **Root Directory** ← C'est ce qu'il faut trouver !

## 🎯 Alternative : Chercher directement

1. **Utilisez la barre de recherche** en haut à gauche
2. **Tapez** : `root directory`
3. **Cliquez** sur le résultat "Root Directory"

## ✅ Une fois que vous trouvez Root Directory

1. **Vérifiez** que le champ est **vide** (dans Project Settings)
2. **Développez** "Production Overrides" si visible
3. **Vérifiez** que le Root Directory là-bas est aussi **vide**
4. **Cliquez** sur **"Save"**
